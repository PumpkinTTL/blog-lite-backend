## 环境说明（重要）

**热重载机制澄清**：项目根 `pnpm all` 用 `concurrently` 同时起 web/admin/api，其中 api 走
`pnpm --dir backend/api dev` → `nest start --watch`，**热重载正常**。

但发现一个历史遗留的 `node dist/main` 进程（PID 38540）抢占了 5100 端口，导致 `nest --watch`
的应用实例启动时端口冲突而挂掉，所有请求都打到不会热重载的 dist 钉子户进程。
已杀掉该进程。**重启 `pnpm all` 后热重载恢复正常。**

> 经验证：本助手全程未启动任何 api 进程，只做了 `nest build`（编译产物）和 `tsc --noEmit`（类型检查）。
> 钉子户进程是环境历史遗留，非本轮操作引入。
